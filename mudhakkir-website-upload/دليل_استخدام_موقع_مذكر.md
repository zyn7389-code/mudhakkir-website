## 1. التشغيل المحلي بضغطة زر واحدة

تم تجهيز ملف تشغيل تنفيذي تلقائي في مجلد المشروع:
* **اسم الملف:** `تشغيل_الموقع.bat`
* **المسار:** `C:\Users\M\.gemini\antigravity\scratch\mudhakkir-website\تشغيل_الموقع.bat`

عند الضغط المزدوج عليه:
1. يتحقق من بيئة Node.js ويثبت الحزم تلقائياً إن لزم الأمر.
2. يشغّل خادم الموقع على المنفذ `3000`.
3. يفتح متصفح الويب تلقائياً على الرابط: `http://localhost:3000`.

## 2. صفحات ومكونات المنصة

| الصفحة | المسار المحلي | الوظيفة |
| :--- | :--- | :--- |
| **الرئيسية** | `index.html` | واجهة المشروع، الهيرو بالشعار المتمركز والخطوط الرسمية، أحدث المواد، تصفح حسب المجال، السلاسل المميزة، ومنهجية العمل في ٤ مراحل. |
| **المكتبة العلمية** | `library.html` | محرك بحث نصي فوري، ٤ فلاتر ذكية (المجال، المقدّم، نوع المادة، الصيغة)، وتبويب «⭐ مكتبتي المحفوظة». |
| **صفحة المادة** | `item.html?id=...` | تفاصيل المادة، معلومات المراجعة، رابط المصدر الأصلي، زر تحميل PDF، زر فتح التفاعلي، وإطار القراءة المدمج. |
| **صفحة المقدِّم** | `speaker.html?name=...` | حصر كامل للمواد والسلاسل الخاصة بمقدّم معين مع تصنيفاتها. |
| **لوحة التحكم** | `admin.html` | لوحة الإدارة الكاملة المخصصة للمدير (إحصائيات، إضافة مادة، تعديل بيانات، حذف). |

## 4. طريقة نشر وإضافة مواد جديدة

من داخل لوحة التحكم:
1. املأ **عنوان المادة** واسم **المقدِّم** (يظهر إكمال تلقائي للمقدّمين المسجلين).
2. اختر **المجال** (فكري، شرعي، تربوي، إلخ) و**نوع المادة** (محاضرة، سلسلة، بودكاست).
3. اختر **حالة المراجعة** («مراجَع كلمةً بكلمة على الأصل» أو «قيد المراجعة»).
4. ضع **رابط المصدر الصوتي أو المرئي الأصلي** (يوتيوب، سحابة صوتية، موقع الشيخ).
5. اكتب **خلاصة ونبذة موجزة** تصف محاور المادة.
6. ارفع الملفات:
   * **الملف التفاعلي (HTML):** النسخة المزودة بالفهرس والبحث والخطوط.
   * **ملف الـ PDF:** النسخة المخصصة للطباعة والمطالعة التقليدية.
   *(يمكن رفع أحدهما أو كلاهما معاً)*.
7. اضغط على **«حفظ ونشر المادة في المكتبة»**، وستظهر فوراً في الرئيسية والمكتبة.

## 5. طريقة تعديل وحذف المواد المنشورة

* **تعديل بيانات مادة (بدون إعادة الرفع):**
  في جدول المواد المنشورة، اضغط على زر **✏️ تعديل** أمام أي مادة لتفتح نافذة التعديل السريع:
  * عدّل العنوان، اسم المقدّم، المجال، نوع المادة، أو الوصف ورابط المصدر.
  * اضغط **«حفظ التعديلات»** لتُحدّث البيانات فوراً في قاعدة البيانات والموقع.
* **حذف مادة:**
  اضغط على زر **🗑️ حذف**؛ سيقوم النظام بتأكيد الحذف وحذف سجل المادة وملفاتها المرفوعة (HTML و PDF) من القرص الصلب بأمان لمنع تراكم الملفات المهملة.

## 6. نشر الموقع على شبكة الإنترنت

المشروع جاهز ومبرمج بأفضل ممارسات الإنتاج ليعمل على أي منصة استضافة سحابية:

### الخيار الأول: النشر السريع والمجاني على Render.com (موصى به)
1. ارفع مجلد المشروع إلى حسابك على **GitHub** (أو GitLab).
2. ادخل على [Render.com](https://render.com) وأنشئ حساباً مجانياً.
3. اضغط على **New +** ثم اختر **Web Service** واربط مستودع GitHub.
4. سيقرأ Render ملف `render.yaml` المرفق تلقائياً، أو حدد الإعدادات يدوياً:
   * **Environment:** `Node`
   * **Build Command:** `npm install`
   * **Start Command:** `node server.js`
   * **Health Check Path:** `/api/health`
5. أضف متغير بيئي: `ADMIN_PASSWORD` بالقيمة التي تريدها.
6. ستحصل على رابط عالمي سريع وآمن (مثل: `https://mudhakkir.onrender.com`) مزود بشهادة SSL مجانية.

### الخيار الثاني: النشر على Railway.app
1. ادخل على [Railway.app](https://railway.app).
2. اختر **New Project** ثم **Deploy from GitHub repo**.
3. سيتعرف Railway على ملف `railway.json` و `Procfile` ويشغّل الخادم فوراً.

### الخيار الثالث: النشر عبر Docker على خادم خاص (VPS)
المشروع مزود بـ `Dockerfile` مُحسّن:
```bash
# بناء حاوية المشروع
docker build -t mudhakkir-website .

# تشغيل الحاوية مع ربط التخزين الدائم
docker run -d -p 80:3000 --name mudhakkir \
  -v mudhakkir_uploads:/usr/src/app/uploads \
  -v mudhakkir_data:/usr/src/app/data \
  mudhakkir-website
```
